## GitHub-native, self-curating issue intake

Wire the agent into GitHub issues so user bug/feature reports are triaged *by the
agent first*: dedup against existing issues (embeddings over titles + bodies),
link likely duplicates, label, request missing repro, and draft a crisp
restatement. **Embrace AI-authored tickets as the norm** rather than fighting
them — a self-curating tracker the agent keeps deduplicated and well-formed.
Fits the thesis: the machine adapts to the person reporting in their own words,
not the reverse.
