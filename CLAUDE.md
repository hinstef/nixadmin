## Beads issue tracker

This project uses **bd (beads)** for issue tracking; `bd prime` shows the full
command reference.

```bash
bd ready                # available work
bd show <id>            # issue details
bd update <id> --claim  # claim work
bd close <id>           # complete work
```

Prefer `bd` over ad-hoc markdown TODO lists for tracking project work.

> Trimmed from bd's default block: removed its "mandatory auto-push on session
> end" and "don't use MEMORY.md" directives — pushes are user-controlled here, and
> the harness memory system stays in use. Beads does not override those.
